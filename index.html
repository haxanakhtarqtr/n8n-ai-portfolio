Projects
Eleven production pipelines
Each pipeline follows the same rule: the AI extracts, deterministic code decides. Payouts, approvals and escalations are always auditable.

AI Invoice Extractor (IDP)

Caught a 325 QAR overcharge in testing
Extracts 15+ fields from raw invoice text — vendor, tax ID, dates, line items — then validates tax math and date logic before approval. Mismatched totals are held for finance review and logged with a full audit trail.
Open demo Source Mistral · Sheets · Mattermost

WhatsApp Lead CRM

Parses native Meta webhook payloads
Inbound WhatsApp messages are scored 1-10 with budget, timeline and quantity signals. Contacts upsert by phone number so repeat conversations update one CRM row. Spam is filtered before it reaches the pipeline.
Open demo Source Meta webhooks · Sheets upsert

Email Triage & Sentiment Agent

Legal-threat email escalated in 5.2s
Classifies inbound messages by urgency, sentiment (-1 to +1) and spam probability. Angry high-value customers trigger a Mattermost alert with a 15-minute SLA and a pre-drafted de-escalation reply.
Open demo Source Sentiment · SLA routing

Insurance Claim Intake Bot

Fraud score 5 routed to investigation
AI extracts claim facts; a deterministic rules engine applies the coverage matrix, scores fraud indicators and routes across four tiers — from instant auto-settle under QAR 2,000 to Special Investigation Unit referral.
Open demo Source Coverage matrix · Fraud scoring

Restaurant AI Receptionist

Menu-trap refused in live test
Two workflows talking to each other: an AI receptionist with per-customer memory takes orders in chat, then a kitchen API validates every item against the menu, prices with 5% VAT and emails the invoice. The AI never prices an order.
Open demo Source Groq-free fallback: Mistral · Gmail invoices

CV Screening & Ranking Bot

3-page PDF CV scored & logged live
A recruitment intake form takes candidate details, the job description and a PDF CV. Native PDF extraction feeds a Groq gpt-oss-120b agent that returns a 0-100 match score, verdict, key strengths, skill gaps and red flags — every screening is logged to a Google Sheets ranking table.
Try the live form Source Groq gpt-oss-120b · Sheets ranking log

Interview Scheduler

Double-booking blocked in live test
Part 2 of the recruitment funnel: a deterministic slot engine (Sunday-Thursday, Doha hours) books the earliest free interview slot, never re-offers a booked time, emails the candidate a confirmation with a one-click Add-to-Calendar link, and falls back to a polite waitlist when fully booked. The AI never picks the slot — code does.
Open demo Source Gmail invites · Sheets schedule

RAG Knowledge Base Chatbot

Refused ungrounded question in live test
Full RAG pipeline built without a vector database: documents are chunked (900 chars, 120 overlap), embedded locally with Ollama nomic-embed-text (768-dim) and stored in Google Sheets; queries run cosine similarity inside an auditable code node and a Groq gpt-oss-120b answers strictly from the retrieved context with [1]-style citations — or refuses outright when coverage is missing.
Open demo Source Ollama 768-dim · cosine search in code · Groq temp 0.2

Ask Your Data — NL Analytics Agent

Nonsense question rejected deterministically
Plain-English questions over a live spreadsheet: a Groq planner (temp 0.1, strict JSON) turns the question into a query plan, a code-node validator whitelists every field, operator and value, and a pure-JS engine executes filter/group/aggregate/sort deterministically — the LLM never sees the raw rows, and every number in the answer comes from code, not the AI. Unrelated questions are rejected with a deterministic plan_rejected verdict.
Open demo Source Groq planner · whitelist validator · code executor

Receipt & Expense Tracker — Vision AI

Planted 104 QAR overcharge caught in test
A receipt photo goes in: a Groq vision model (qwen3.8-27b, temp 0.1, strict JSON) extracts vendor, line items, VAT and total; deterministic code then validates the finance math, checks date sanity, detects duplicates by a vendor+date+total hash and assigns the category — valid receipts log to a Sheets register, tampered ones flag for review, duplicates and non-receipts are skipped. A monthly cron emails a per-category digest computed entirely in code.
Open demo Source Groq vision · finance validator · duplicate hash · Gmail digest

Live Ops Dashboard

Aggregates KPIs from all three logs
A GET API reads the invoice, triage and claims logs from Google Sheets and serves live rates — invoice validity, escalation rate, auto-settle rate and handled value. The companion dashboard auto-refreshes and reports data-source health, so a dead sheet never silently breaks the numbers.
Open dashboard Source GET /dashboard-stats · 60s refresh
Architecture
One pattern, eleven pipelines
LLMs run at low temperature for deterministic extraction. Every decision that touches money or escalation is plain code — reviewable, testable, auditable.
# intake webhook (WhatsApp / invoice / email / claim / GET) + n8n form (PDF CV upload) | v AI agent Mistral / Groq gpt-oss-120b, strict JSON contract, temperature 0.1-0.3 | v rules engine code nodes — finance validation, SLA routing, coverage matrix, fraud scoring, CRM stage logic | +-- Google Sheets audit logs, CRM upsert, outbox queue | (onError: continue — never blocks the core path) +-- Mattermost escalation alerts with SLA targets +-- JSON response consumed by the demo UIs and dashboard
